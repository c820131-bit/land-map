# INVESTMENT MAP — 새 Claude 창 시작 지침 (프로젝트 지침/CLAUDE.md 에 넣는 문구)

사용자가 "INVESTMENT MAP <역할> 인계받고 이어서 작업해" 라고 말하면 (역할 = A·B·C·D·E·H):

1. 프로젝트 루트에서 `_HANDOFF/handoff.py` 를 찾는다. 없으면 인계 불가라고 정직하게 보고한다(성공으로 꾸미지 않는다).
2. 먼저 `_HANDOFF/PROJECT_CHARTER.md` 를 읽는다.
3. 다음을 실행하고 브리핑 전체를 읽는다. 세션 ID는 역할-날짜-임의문자(예: `C-20261108-k3f`)로 만든다.
   `python _HANDOFF/handoff.py --session <세션ID> takeover <역할>`
   - 종료코드 3(다른 창이 사용 중)이면 **절대 --force 하지 말고** 사용자에게 알린다.
   - 역할이 지정되지 않았으면 `status` 만 실행해 보여 주고 어떤 역할을 맡을지 묻는다.
4. 브리핑의 ✔ 완료 작업은 다시 하지 않는다. "다음 안전 작업"부터 `task start` 로 시작한다. "사용자 승인 대기" 작업은 자동 실행하지 않는다.
5. 격리 작업 영역(브리핑 [2])과 변경 금지 파일 밖의 파일은 수정하지 않는다. 루트 운영 파일과 다른 역할의 폴더는 읽기만 한다.
6. 오류는 즉시 `error add` 로 기록한다. 결과물은 `candidate register` 로 SHA 고정한다. 작업을 마치거나 창을 닫기 전에
   `checkpoint <역할> --file ... --next-command ... --report-file ... --release` 로 인계 기록을 남긴다.
7. 30분 이상 작업이 이어지면 `heartbeat <역할>` 을 실행한다(임대 TTL 1시간).
8. 보고할 때는 "독립 검수 합격판"과 "최신 개발 후보"를 구분해 말하고, 검증하지 않은 것을 성공이라고 쓰지 않는다.
